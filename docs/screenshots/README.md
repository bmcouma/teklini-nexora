# Screenshots

This folder is reserved for dashboard and investigation-view screenshots. Add them here once the
application is deployed or run locally, for example:

```bash
docker compose up --build
# then capture:
#   dashboard.png        - the incident list view
#   new-incident.png     - the incident submission form
#   investigation.png    - a completed investigation with root cause and recommendations
```

No screenshots are committed yet; this project was built and verified via its automated test
suite (`pytest`, `npm run build`) rather than a live deployment with a browser available at
generation time.
